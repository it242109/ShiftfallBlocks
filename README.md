#### 2. 概要
##### コンセプト：「仕掛けを解き、ゴールを目指す」
プレイヤーは、ステージ内に用意された様々なギミックを「仕掛けブロック」を使って攻略していく。
仕掛けブロックは、スイッチの上に置くことで扉を開いたり、新たな仕掛けを作動させたりすることができ、ステージクリアのカギとなる。
落とし穴、扉など障害物の前にスイッチがあることがヒントである。それに対応する「仕掛けブロック」を置けばうまく作動するかもしれない。

#### 3. 操作説明
###### ＜ゲームプレイ時＞
| 操作          | 内容          |
| ----------- | ----------- |
| WSADキー      | 移動          |
| スペースキー      | ジャンプ        |
| 左シフトキー＋移動キー | ダッシュ        |
| マウス回転       | 視点移動        |
| 右クリック       | 持つ／置く       |
| 左クリック       | 攻撃          |
| Eキー         | アイテム入手      |
| マウスホイール回転   | 攻撃できる距離を変える |
| Tキー         | ポーズ         |

##### ＜タイトル／セレクト／リザルト＞
| 操作              | 内容 |
| --------------- | -- |
| 上下キー または WASDキー | 選択 |
| スペースキー          | 決定 |

#### 4. アピールポイント
#####  ステージ構成とクリアタイムの記録
　JSONファイルを用いてステージ構成やクリアタイムの記録を実装しました。
　ステージでは、壁と床を位置と大きさに分けて書き込んでいます。
　また、タイムを記録するときは、クリア時にJSONファイルとして記録し、記録したデータをほかのシーンで表示するようにしました。

##### スイッチの処理
　スイッチごとに、仕掛けを作動するかどうかを列挙体と関数オブジェクトを利用して実装しました。「どのブロックだったらスイッチが作動するか」という謎解きのような仕組みになりました。

##### 敵の処理
　ステートマシンを利用して、敵の動きや状態を分けました。
　列挙体で各状態を分けて、その状態に応じて処理を行っています。
　また、敵の追尾システムでは、敵からプレイヤーへのベクトルを計算し距離に応じて移動できるかを判断したうえで、プレイヤーに向かって自然に移動させています。
